Activity API v1

Scripts run in an isolated Firefox USER_SCRIPT world and can only send normalized reports through ChudPresence.report().

ChudPresence.report({
  title: "Episode title",
  artist: "Series name",
  url: location.href,
  playing: true,
  position: 120,
  duration: 1440,
  kind: "episode"
});
